🛡️ 臺北市政府警察局合法取締與「預告標誌」防治須知

1. 法定預告距離：依《道路交通管理處罰條例》第 7-2 條，無論是固定式測速桿或移動式測速照相（三腳架/警車雷射），一般道路應於 100公尺至300公尺 前、高架/快速道路應於 300公尺至1000公尺 前明顯設置「前有測速照相」（警52）標誌。若現場無標誌或被路樹遮擋，可依法提起申訴撤單。

2. 移動式常出沒時段與特徵：北市移動式黑箱（三腳架）多於週末清晨 06:00–10:00、平日離峰 10:00–16:00 及夜間 22:00–02:00 架設於建國高架避車彎、水源快果菜市場段、仰德大道下山、大度路、市民大道平面（限速 40）及環東大道。

3. 區間測速防範（自強隧道、辛亥隧道）：兩處隧道皆為雙向速限 50 km/h，只要隧道內全程平均時速不超過 60 km/h（換算通過約 900 公尺隧道時間不少於 54 秒），並切勿跨越雙白線變換車道，即可安全通過。

如何放到手機與車架上實戰使用（車規升級版）

✨ 已為您升級 4 大實戰車規功能：
  • 連續 GPS 追蹤（watchPosition）：點擊「📍 連續 GPS 導航」後，系統會每秒自動讀取手機 GPS 經緯度、真實車速與行車航向角。
  • 智慧航向角（Bearing）比對：自動計算車頭行進方向（東/西/南/北），並判斷前方測速桿是否為「同向執法」或「對向車道免驚」。
  • 螢幕恆亮不休眠（Wake Lock API）：點擊頂部「💡 螢幕恆亮」即可防止手機在車架上黑屏斷開語音。
  • 前擋風玻璃投影模式（🪞 前擋投影 HUD）：一鍵將 HUD 卡片左右鏡像翻轉，夜間平放於儀表板即可反射在前擋風玻璃上！

🚀 三步驟安裝到手機桌面（完全免費）：

1. 下載或部署此網頁檔：將這份單一 HTML 檔案上傳至免費靜態空間（如 GitHub Pages、Netlify Drop 或 Vercel），直接拖曳檔案即可獲得專屬 https:// 網址。

2. 加入手機主畫面（PWA 全螢幕模式）：用 iPhone (Safari) 或 Android (Chrome) 開啟網址，點選「分享 ➔ 加入主畫面」，桌面上就會出現「北市測速雷達」App 圖示，打開時會隱藏瀏覽器網址列。

3. 上車一鍵啟動：上車後打開 App，點選頂部「💡 螢幕恆亮」與「📍 連續 GPS 導航」，即可開始全自動語音預警！
